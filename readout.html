What we established in the discussion

40 to 50% of studios go live within two weeks. The rest take four to six.

Every late studio had a data issue. About a third also missed a training call.

Two data patterns: the first file arrives in week three or four, or arrives in week one but is not usable until week four.

Platform A is mostly on time, B is mixed, C is always late. Follow-up frequency did not separate outcomes.

First follow-up lands in week three or four. One forwarded thread suggests the studio only passed the request to its provider that late.

Still open: why C exports run long, and how the days split between request, first file and usable file.

Decisions this readout puts on the table

1. Make “export request sent” a handoff-call milestone

Owner: onboarding lead

The request is already made on the call and emailed. The gap is the studio sending it. Ask for the acknowledgment or request number, and for platform C start the provider request at signature.

2. Agree the first-file date, then work back from day 14

Owner: onboarding lead

Reserve about four working days after a usable file for corrections, migration and testing. The first-file date is the one that protects go-live.

3. Follow up on day 2 to 3, and phone if the file is missing

Owner: onboarding lead

Today the first follow-up lands after the target has passed. Validate the first file the day it arrives and return exact corrections.

4. Confirm when the first invoice triggers

Owner: Finance

In the sample, of first-invoice value bills at go-live. If Kenko bills differently, the cash effect changes, so confirm before sizing it.

5. Run one weekly readout

Owner: head of Customer Experience

Same page every week: what is resolved, what is blocked, who acts next, and when leadership steps in.

How I would run the first 90 days

Days 1 to 30

Reconstruct five late and five on-time studios from the handoff email, file uploads and migration records, matched by platform. Then record request, first-file and usable-file dates for every migration in flight.

Days 31 to 60

Pilot the request milestone, the first-file date and day 2 to 3 follow-up on one cohort, starting with platform C. Compare against the baseline.

Days 61 to 90

Weekly readout live, onboarding leads own root-cause reviews, first cohort result shared with Finance and Sales.
